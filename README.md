# Dashboard de Análise Logística

Projeto prático desenvolvido durante a especialização em Power BI.

## Tecnologias
- Power BI
- DAX
- Modelagem de Dados
- Power Query
- Figma

Projeto prático desenvolvido durante minha especialização em Power BI, com o objetivo de construir um dashboard interativo para análise de indicadores de logística, entregas, custos e performance operacional.

O projeto utiliza dados simulados para reproduzir um cenário de análise empresarial, permitindo explorar diferentes perspectivas e identificar padrões, oportunidades e pontos de atenção nos indicadores.

Durante o desenvolvimento, trabalhei na estruturação do modelo de dados e na criação de recursos de análise e visualização no Power BI, incluindo:

• Criação e utilização de Tabela Calendário;
• Relacionamentos entre tabelas, cardinalidade e direção de filtro;
• Criação e organização de uma Tabela de Medidas;
• Desenvolvimento de medidas e cálculos utilizando DAX;
• Construção de KPIs e indicadores de performance;
• Análise de OTIF, On Time, In Full, custos, margem, receita e ocorrências;
• Análise hierárquica por tipo de veículo e filial;
• Desenvolvimento de gráficos, cartões, tabelas e elementos de análise;
• Criação de Tooltips personalizados para ampliar a exploração dos dados;
• Utilização de botões de navegação para melhorar a experiência de interação;
• Desenvolvimento da identidade visual e elementos da interface utilizando Figma.

O dashboard foi estruturado para permitir uma navegação intuitiva entre diferentes visões, possibilitando uma análise mais rápida dos indicadores e apoiando a interpretação dos dados para tomada de decisão.

Principais aprendizados: modelagem de dados no Power BI, construção de medidas em DAX, criação de dashboards interativos, organização de indicadores e aplicação de conceitos de UX na visualização de dados.

Este projeto faz parte da minha formação em Análise de Dados e representa uma etapa importante na construção do meu portfólio profissional na área de Dados e Business Intelligence.
